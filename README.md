# Багратион

Адаптивный информационный сайт спортивного клуба карате киокушин «Багратион». Проект подготовлен как статический MVP для размещения на виртуальном хостинге Timeweb.

## Что уже работает

- адаптивная главная страница для компьютеров и мобильных устройств;
- первый экран с презентацией клуба и кнопкой звонка;
- три актуальные новости с плавным перелистыванием и мобильным свайпом; до первого взаимодействия и при переходе к любому другому разделу они меняются каждые 5 секунд, а пока в навигации активны «Новости», управляются вручную;
- разделы о клубе, достижениях и возможностях учеников;
- карточки 8 тренеров и сведения об 11 залах;
- модальные окна тренеров с биографией, увеличенными адаптивными расписаниями и интерактивными картами;
- локальные карты OpenStreetMap без загрузки стороннего виджета при открытии страницы;
- одна общая карта с четырьмя залами для Кураш;
- переход к выбранному адресу в Яндекс Картах только по нажатию пользователя;
- календарь с 18 официальными мероприятиями августа–ноября 2026 года и отдельными состояниями до выбора даты и для пустой даты;
- адаптивная фотогалерея и переход в Telegram-архив клуба;
- нижний блок с прямым звонком в клуб и подвал сайта.

Онлайн-запись и форма обратной связи убраны. Сайт не принимает и не отправляет персональные данные посетителей: связь происходит через обычную телефонную ссылку `tel:`.

## Технологии

- Next.js 16 с App Router и статическим экспортом;
- React 19;
- TypeScript;
- Tailwind CSS;
- Lucide React;
- локальные данные OpenStreetMap для интерактивных карт.

## Структура проекта

```text
app/                 страница, метаданные и глобальные стили
components/          общие компоненты и локальная интерактивная карта
sections/            основные секции главной страницы
public/              изображения, шрифты и данные карт
public/maps/         локальные данные OpenStreetMap
PROBLEMS.md           актуальный список готовности и оставшихся задач
```

Основные данные тренеров, адреса, расписания и ссылки на Яндекс Карты находятся в `sections/Coaches.tsx`. Новости находятся в `sections/News.tsx`, календарь — в `sections/Events.tsx`, данные локальных карт — в `public/maps`.

## Локальный запуск

Требуется актуальная LTS-версия Node.js.

```powershell
npm.cmd ci
npm.cmd run dev
```

После запуска сайт доступен по адресу `http://localhost:3000`.

## Проверки

```powershell
npx.cmd tsc --noEmit
npm.cmd run lint
npm.cmd audit --audit-level=moderate
npm.cmd run build
```

На 24 августа 2026 года TypeScript и production-сборка проходят без ошибок, `npm audit` сообщает о 0 известных уязвимостях. ESLint проходит с 14 предупреждениями об использовании обычных `<img>`.

Локальная production-сборка дополнительно проверена в headless Chrome на ширинах 390 и 1366 px: горизонтального переполнения нет, календарь, модальное окно тренера и режимы автопрокрутки новостей работают.

Команда сборки создаёт статическую версию сайта в папке `out`. Готовую сборку можно проверить локально:

```powershell
npm.cmd run preview
```

Предпросмотр будет доступен по адресу `http://127.0.0.1:3001`.
