# Багратион

Сайт спортивного клуба карате киокушин «Багратион».

Проект создается как новая версия клубного сайта: современный информационный лендинг с основными разделами о клубе, тренерах, способе связи по телефону, фотоальбомах и будущими модулями для новостей, мероприятий и администрирования контента.

Цель проекта — сделать удобный, визуально цельный и расширяемый сайт клуба, который можно будет постепенно развивать: добавлять новые секции, подключать данные с backend и управлять новостями, тренерами и расписанием через админ-панель.

## Основные Разделы

- Первый экран с представлением клуба.
- Блок «О клубе».
- Секция тренеров с карточками.
- Контактный блок с прямым звонком в клуб.
- Фотоальбомы с мероприятий.
- В дальнейшем: новости, календарь мероприятий, контакты, подвал и админ-панель.

## Стек

- **Next.js** — React-фреймворк для структуры сайта, маршрутизации и сборки.
- **React** — компонентный подход к интерфейсу.
- **TypeScript** — типизация данных и компонентов.
- **Tailwind CSS** — стилизация интерфейса через utility-классы.
- **lucide-react** — иконки для интерфейсных элементов.

## Подход

Сайт собирается модульно: каждая крупная часть страницы вынесена в отдельную секцию, а повторяющиеся элементы оформляются как компоненты. Такой подход упрощает поддержку проекта и позволит в дальнейшем безболезненно подключить backend и админ-панель.

## Статическая сборка для Timeweb

Проект настроен для обычного виртуального хостинга Timeweb. Команда сборки создаёт папку `out`, содержимое которой можно загрузить в корневую директорию тестового сайта.

```powershell
npm.cmd install
npm.cmd run build
```

Для локальной проверки уже собранной папки `out`:

```powershell
npm.cmd run preview
```

После запуска статическая версия доступна по адресу `http://127.0.0.1:3001`.

### Индексация

По умолчанию поисковая индексация запрещена. Это безопасный режим для технического домена `cp29116.tw1.ru`.

Для будущей сборки основного домена создайте `.env.production.local`:

```text
NEXT_PUBLIC_ALLOW_INDEXING=true
```

После изменения переменной необходимо заново выполнить `npm.cmd run build`. Не включайте индексацию для тестового домена.
