# Состояние реализации

Обновление 23.10.2026: список по датам и независимая сортировка событий внутри каждого дня; проверены SQL/XSS/CSRF, Origin, вход/TOTP/блокировки/сессии, загрузки и запрет служебных файлов. Подробности и ограничения — SECURITY-REVIEW.md. Восстановление свежей production-копии базы/медиа/конфигурации проверено без замены рабочих данных. Ниже сохранена запись первоначального этапа разработки.

Реализованы PHP/MySQL CMS новостей и событий, ручное создание и отзыв администраторов, пароль Argon2id и TOTP, сессии, CSRF, ограничения входа, аудит, версии черновиков, публикация статического JSON, загрузка и перекодирование изображений, ограниченные по времени ссылки предпросмотра, импорт текущего контента и сохранение shared-каталогов при деплое.

В Docker проверены синтаксис всех PHP-файлов, векторы TOTP, валидация, установка схемы MySQL, HTTPS-вход с паролем и TOTP, сохранение черновика события, публикация в статический JSON, снятие с публикации, выход и запрет HTTP-доступа к служебным файлам. Главная страница возвращает HTTP 200 с заголовком «Багратион». TypeScript проходит проверку. В GitHub Actions добавлены PHP-проверки; Actions ещё не запускался. Загрузка файлов, восстановление резервной копии, конкурентное редактирование и визуальная приёмка остаются отдельными проверками перед production.

Перед production обязательно выполнить серверную приёмку по INSTALL.md, включая восстановление резервной копии. Не заявлять CMS безопасной или полностью проверенной до этой приёмки.

Ограничения первой версии: все администраторы имеют одинаковые редакторские права; выдача/отзыв доступа только через SSH. Предпросмотр показывает текст/фото, но не точную раскладку карусели. Проверка 70% квоты доступна командой CLI для каталога Bagration; полный расход аккаунта контролируется в Timeweb. Неиспользуемые загруженные изображения автоматически не удаляются. Миграция v1 идемпотентна; следующие изменения схемы потребуют отдельной версионной миграции.
