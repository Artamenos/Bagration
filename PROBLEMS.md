## Проверки перед тестовой публикацией

```powershell
npx.cmd tsc --noEmit
npm.cmd run lint
npm.cmd audit --audit-level=moderate
npm.cmd run build
npm.cmd run preview
```

Текущее состояние проверок:

- TypeScript — без ошибок;
- ESLint — 0 ошибок, 14 предупреждений `@next/next/no-img-element`;
- `npm audit` — 0 известных уязвимостей, включая dev-зависимости;
- production build — успешно, статический экспорт сформирован в `out`;
- локальный preview — главная и `robots.txt` отвечают HTTP 200, неизвестный путь возвращает 404;
- 32 локальных ресурса из сгенерированного HTML отвечают HTTP 200, битых путей нет;
- staging-сборка содержит `noindex, nofollow`, `robots.txt` запрещает обход;
- тестовые формы, API заявок, поля ввода и PHP-файлы в `out` отсутствуют;
- локальный `out` содержит все ресурсы, но 13 используемых изображений пока не отслеживаются Git;
- headless Chrome на 390 и 1366 px не выявил горизонтального переполнения; календарь, модальное окно тренера и три режима карусели новостей проверены;
- перед заменой основного сайта остается короткая ручная приемка на реальном телефоне и компьютере.

## Ближайший практический этап

1. Подтвердить права клуба на публикацию фотографий.
2. Проверить интерфейс на ширинах 360, 390, 768, 1024, 1366 и 1920 px, включая все модальные окна и карты.
3. Перед коммитом добавить 13 используемых новых изображений.
4. Минимизировать OSM-файлы и оптимизировать тяжелые изображения.
5. Собрать `out` с выключенной индексацией и опубликовать на тестовом домене.
6. После приемки подключить основной домен, HTTPS, security headers и разрешить индексацию.
