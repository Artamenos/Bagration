# P0 — блокеры публикации

## 1. ~~Production-сборка завершается ошибкой~~ — исправлено

**Статус:** исправлено 18.08.2026.

Файлы:

- `app/robots.ts`
- `next.config.ts`

Исходные проблемы:

- Проект использует `output: "export"` для статической выгрузки на Timeweb.
- Маршрут `/robots.txt` не настроен как полностью статический.
- `npm run build` компилирует приложение и проходит TypeScript, но падает во время сбора данных для `/robots.txt`.
- Готовая папка `out` не создаётся корректно.
- В текущем состоянии проект нельзя загрузить на обычный виртуальный хостинг Timeweb.
- Скрипт `next start` в `package.json` не соответствует режиму статического экспорта.

Что сделано:

- Маршрут `robots.txt` переведён в принудительно статический режим.
- Индексация разделена для staging и production через `NEXT_PUBLIC_ALLOW_INDEXING`.
- Команда `next start`, несовместимая со статическим экспортом, заменена на `npm run preview`.
- Добавлен локальный preview готовой папки `out` без сторонних зависимостей.
- `npm run build` успешно формирует главную страницу, 404 и `robots.txt`.
- Готовая папка `out` проверена через обычный статический HTTP-сервер.
- Для тестовой сборки подтверждены `noindex` и `Disallow: /`.

## 2. ~~Форма записи не обрабатывает заявку~~ — исправлено и проверено

**Статус:** ✅ исправлено 19.08.2026, успешная доставка тестовой заявки подтверждена владельцем сайта.

Файлы:

- `sections/Signup.tsx`
- `public/api/contact.php`
- `public/api/phpmailer/`

Что сделано:

- Реализован контролируемый `onSubmit` с `preventDefault()`.
- Форма отправляет JSON через `POST` в PHP-обработчик.
- Настроена доставка заявок через SMTP Яндекс.Почты с помощью PHPMailer.
- Добавлены состояния `idle`, `submitting`, `success` и `error`.
- Форма очищается только после подтверждённой успешной отправки.
- Добавлены серверная валидация, honeypot и ограничение частоты запросов.
- Выполнен реальный тест на Timeweb: заявка обработана и доставлена на почту.

## 3. ~~Персональные данные отправляются через URL~~ — исправлено

**Статус:** ✅ исправлено 19.08.2026.

Файлы:

- `sections/Signup.tsx`
- `public/api/contact.php`

Что сделано:

- Стандартная GET-отправка формы заблокирована через `preventDefault()`.
- Имя, телефон, группа и зал передаются в JSON-теле `POST`-запроса.
- Персональные данные не добавляются в query-параметры URL.
- После отправки URL страницы не содержит имя, телефон или другие поля формы.
- PHP-обработчик принимает только `POST` с `Content-Type: application/json`.
- Ответы API запрещено кэшировать через `Cache-Control: no-store`.

Примечание:

- Для реальных, а не тестовых данных перед постоянной публикацией всё равно требуется корректный HTTPS.

# P1 — критические проблемы MVP

## 8. На мобильных устройствах отсутствует навигация

Файл: `components/Header.tsx`

Проблемы:

- Навигация скрыта до breakpoint `md`.
- Кнопки мобильного меню нет.
- Пользователь телефона не может перейти к разделам сайта.
- На ширине около 768–900px полное desktop-меню уже отображается, но не помещается вместе с логотипом и названием.

Что требуется:

- Добавить мобильную кнопку меню.
- Реализовать доступное раскрывающееся меню.
- Закрывать меню после выбора пункта.
- Поддержать закрытие по Escape.
- Перенести полную desktop-навигацию на более широкий breakpoint.

## 9. Карточка новости сломана на мобильной ширине

Файл: `sections/News.tsx`

Проблемы:

- Карточка использует `flex`, но не `flex-col`.
- Направление остаётся горизонтальным на телефоне.
- Изображение имеет `w-full flex-none` и занимает всю ширину.
- Текст выталкивается за пределы карточки.
- `overflow-hidden` скрывает вытолкнутый текст.

Что требуется:

- Использовать вертикальную компоновку на mobile.
- Переключать её на горизонтальную только на достаточной ширине.
- Отказаться от жёсткой высоты карточки на узких экранах.

## 10. Сетка тренеров создаёт горизонтальное переполнение

Файл: `sections/Coaches.tsx`

Проблемы:

- При ширине от 1024px включаются пять колонок по 240px.
- Вместе с промежутками сетке требуется около 1296px.
- Полезная ширина экрана 1024px составляет около 976px.
- Блок выходит за границы страницы на планшетах и небольших ноутбуках.

Что требуется:

- Использовать адаптивный `repeat(auto-fit, minmax(...))` или последовательность 2/3/4/5 колонок.
- Проверить ширины 1024, 1152, 1280 и 1366px.

## 11. Модальное окно тренера не помещается по высоте

Файл: `sections/Coaches.tsx`

Проблемы:

- Высота окна жёстко задана как 740px.
- Внешние вертикальные поля увеличивают требуемую высоту примерно до 804px.
- Окно не помещается на экране 1366×768.
- Внешняя оболочка не прокручивается.
- Пользователь может не увидеть часть содержимого или кнопки закрытия.

Что требуется:

- Использовать `max-height` относительно viewport.
- Разрешить вертикальную прокрутку содержимого.
- Сохранить доступность кнопки закрытия.

## 12. Модальное окно тренера полностью не адаптировано для телефона

Файл: `sections/Coaches.tsx`

- Это снижает, но не отменяет необходимость обновления и повторной проверки.

## 55. Не настроены security headers

Для Timeweb необходимо проверить и при необходимости добавить:

- Content-Security-Policy;
- X-Content-Type-Options;
- Referrer-Policy;
- Permissions-Policy;
- защиту от встраивания сайта в чужие iframe;
- корректный HTTPS redirect.

## 56. Яндекс Карта не ограничена

Файл: `sections/Coaches.tsx`

- У iframe нет `sandbox`.

- Пользовательские технические данные передаются стороннему сервису.
- Это не отражено в политике.

# P4 — незначительные и редакторские проблемы

## 64. Непоследовательная типографика диапазонов

Файлы:

- `sections/Coaches.tsx`
- `sections/Events.tsx`
- `components/Footer.tsx`

Примеры:

- `2012-2019` вместо `2012–2019`;
- `18:00 - 19:00` вместо `18:00–19:00`;
- `Пробное занятие - бесплатно` вместо `Пробное занятие — бесплатно`;
- `главное - удобная спортивная форма` вместо `главное — удобная спортивная форма`.

## 65. Ошибка в формулировке учебного года

Файл: `sections/Coaches.tsx`

Текущий текст:

```text
2,3 год обучения
```

Предпочтительно:

```text
2–3-й год обучения
```

## 66. Непоследовательное написание «призёр»

Проблемы:

- Встречаются разные варианты `призер` и `призёр`.
- Следует выбрать одну редакционную норму.

## 67. Необоснованная заглавная буква внутри предложения

Файл: `sections/Coaches.tsx`

Пример:

```text
...призеров всероссийских первенств, Чемпиона Москвы...
```

Слово «чемпиона» должно быть со строчной буквы.

## 68. Сокращения спортивных организаций не расшифрованы

Файл: `sections/Coaches.tsx`

Примеры:

- КАН;
- ШИН;
- ИКО;
- ИФК;
- KWU.

Для широкой аудитории требуется расшифровка или пояснение.

## 69. Формулировка «Кандидатский уровень» непонятна

Файл: `sections/Coaches.tsx`

Проблемы:

- Неясно, относится ли она к кю, разряду, должности или стажировке.
- Не выглядит как официальная квалификация.

## 70. Роль президента клуба указана неполностью

Файл: `sections/Coaches.tsx`

Текущий текст сообщает о должности президента региональной организации, но не называет саму организацию полностью.

## 71. Ссылки «Читать» и «Подробнее» ведут на главную старого сайта

Файлы:

- `sections/News.tsx`
- `sections/Events.tsx`

Проблемы:

- Пользователь ожидает конкретный материал.
- Вместо него открывается главная страница.
- Новая вкладка открывается без пояснения.

## 72. Footer повторяет рекламный тезис вместо полезной информации

Файл: `components/Footer.tsx`

Проблемы:

- «Пробное занятие — бесплатно» уже указано в Hero.
- В подвале полезнее разместить режим работы, email или юридическую ссылку.

## 73. Заголовки секций имеют слишком одинаковый масштаб

Проблемы:

- Большинство `h2` используют `text-5xl`.
- Страница выглядит как последовательность одинаково громких блоков.
- Иерархия контента недостаточно выражена.

## 74. Слишком много одинаковых светлых карточек и теней

Проблемы:

- Повторяются белый фон, светло-голубой фон, радиус 4px и `shadow-sm`.
- Разные типы контента визуально недостаточно различаются.

## 75. Используются прямые цвета вне дизайн-токенов

Пример:


Проблемы:

- Не все состояния цвета управляются через CSS-переменные.
- Сложнее менять тему и проверять контраст.

## 76. Ключи элементов местами используют индекс

Файлы:

- `sections/Coaches.tsx`
- `sections/Albums.tsx`

Проблемы:

- При динамическом изменении порядка элементов индекс может приводить к неправильному повторному использованию DOM.
- Для текущих статических данных риск небольшой.

## 77. README устарел

Файл: `README.md`

Проблемы:

- Новости, события, контакты и подвал описаны как будущие модули.
- Они уже реализованы в проекте.
- Нет инструкции сборки для Timeweb.
- Нет описания staging-режима.
- Нет списка необходимых переменных окружения.

## 78. Рабочее дерево содержит несохранённые и удалённые файлы

На момент аудита:

- удалён `AGENTS.md`;
- удалён `CLAUDE.md`;

Перед релизом требуется:

- не включать случайные удаления;
- сформировать осознанный релизный commit.
