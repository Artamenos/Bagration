# Локальные картографические данные

В каталоге находятся открытые данные OpenStreetMap для районов, где расположены залы тренеров:

- `timiryazevskaya.osm.json` — Тимирязевский район Москвы;
- `vernadskogo.osm.json` — район проспекта Вернадского;
- `raspletina.osm.json` — район улицы Расплетина;
- `lobnya.osm.json` — район улицы Чехова в Лобне;
- `aprelevka.osm.json` — залы в Апрелевке.

Координаты маркеров и подписи залов перенесены из Яндекс-карт старой версии сайта. У Анастасии Кураш сохранены все четыре маркера старой карты: Августовская улица, Жасминовая улица, Парковая улица и улица Самохина.

- Источник: OpenStreetMap через Overpass API.
- Дата получения: 20 августа 2026 года.
- Лицензия данных: Open Database License (ODbL).
- Атрибуция: © OpenStreetMap contributors — https://www.openstreetmap.org/copyright

Файлы хранятся и отдаются с того же хоста, что и сайт. Интерактивные карты не загружают сторонние тайлы, скрипты, iframe или API в браузере посетителя.

Кнопка «Открыть в Яндекс Картах» является обычной внешней ссылкой. Соединение с Яндексом создаётся только после самостоятельного нажатия посетителя.
