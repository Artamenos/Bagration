# Настройка формы обратной связи на Timeweb

## Требования

- PHP 8.1 или новее.
- HTTPS для тестового домена.
- В Яндекс Почте включены пароли приложений и доступ почтовых программ.
- Исходящее SMTP-соединение использует обязательный STARTTLS на порту 587.

## Закрытый конфигурационный файл

1. Скопируйте `deployment/bagration-contact.example.php`.
2. Переименуйте копию в `bagration-contact.php`.
3. Заполните `smtp_password` паролем приложения Яндекс Почты.
4. Замените `rate_limit_salt` случайной строкой длиной не менее 32 символов.
5. Загрузите файл на Timeweb уровнем выше папки `public_html`.

Пример расположения:

```text
/home/.../bagration-contact.php
/home/.../public_html/api/contact.php
```

Файл `bagration-contact.php` нельзя размещать в `public_html`, добавлять в Git или отправлять в переписке.

## Публикация

После `npm run build` содержимое папки `out` загружается в `public_html`. В сборку автоматически входят:

- `api/contact.php`;
- PHPMailer;
- статические файлы сайта.

## Проверка

1. Откройте сайт по HTTPS.
2. Заполните форму реальными тестовыми данными.
3. Убедитесь, что появилось сообщение об успешной отправке.
4. Проверьте получение письма на `kyokushinprofi@yandex.ru`.
5. Не проверяйте форму чаще трёх раз за 15 минут с одного IP.

Если домен изменится, добавьте новый HTTPS-адрес в `allowed_origins` закрытого конфигурационного файла.
