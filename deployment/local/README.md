# Локальная проверка

Открыть Docker Desktop. В папке проекта выполнить `npm run local`. Первый запуск скачивает MySQL и собирает PHP; последующие используют готовые образы.

Сайт: https://localhost:8443/ — админка: https://localhost:8443/admin/.
Самоподписанный сертификат работает только для локальной проверки. В браузере разрешить переход к localhost через «Дополнительно». Не нужно устанавливать его в доверенные сертификаты Windows.

В другом терминале выполнить `npm run local:account`: команда создаст отдельного тестового администратора и покажет его логин, пароль, TOTP-секрет и текущий код. Код меняется каждые 30 секунд и используется один раз. Можно добавить секрет в приложение-аутентификатор или повторно запускать команду для получения свежего кода. Эти данные предназначены только для локального окружения и не подходят для хостинга.

Проверить создание черновика, предпросмотр, публикацию, снятие с публикации и загрузку изображения. После публикации обновить главную страницу. База и фотографии сохраняются в Docker volumes после остановки.

Остановка: Ctrl+C в терминале сайта и `npm run local:stop`. Повторный запуск: `npm run local`. Docker не нужен посетителям сайта и не требуется на Timeweb: здесь он заменяет локальную установку Apache, PHP и MySQL.

PHP-синтаксис: `docker compose exec web sh -c 'find /srv/Bagration/releases/local/admin -name "*.php" -exec php -l {} \;'`.
Тесты TOTP/валидации: `docker compose exec web php /srv/Bagration/releases/local/admin/test.php`.

Доступ к HTTPS-порту привязан к 127.0.0.1, порт MySQL наружу не публикуется. Next.js dev-сервер слушает порт 3000 для соединения из Docker; не разрешайте доступ к нему из публичных сетей в Windows Firewall. Для реального сайта используются отдельная база, пароли и сертификат Timeweb.
